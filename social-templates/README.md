# ALMATE · Plantillas para redes sociales

Plantillas visuales editables (SVG) con la identidad de ALMATE. Abrilas en Figma, Illustrator, Inkscape o cualquier editor SVG, reemplazá los textos y las fotos de producto, y exportá a PNG/JPG para publicar.

## Archivos

- `ig-post-producto.svg` — Post cuadrado de Instagram (1080×1080) para un producto destacado.
- `ig-post-categoria.svg` — Post cuadrado con 3 productos de una categoría.
- `ig-story-promo.svg` — Historia de Instagram (1080×1920) con oferta y precio tachado.
- `wa-status.svg` — Estado de WhatsApp (1080×1920).

## Identidad visual

- Grafito `#1c1b22` (textos y contornos)
- Blanco cálido `#fff7ee` (fondo)
- Azul eléctrico `#3b82f6`
- Naranja intenso `#ff6b35`
- Amarillo cálido `#fbbf24`
- Verde lima `#a3e635`
- Rosa/coral `#ff4d6d`
- Tipografía display: Bricolage Grotesque (fallback Arial Rounded / Trebuchet)
- Tipografía cuerpo: DM Sans

## Uso

1. Abrí el SVG en tu editor.
2. Reemplazá "Nombre del producto", "Cód. 0000" y los precios.
3. Reemplazá los rectángulos punteados por la foto del producto (mantener relación de aspecto).
4. Exportá a PNG (1080×1080 o 1080×1920) y publicá.
